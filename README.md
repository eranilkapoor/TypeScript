# TypeScript

A step-by-step, beginner-to-expert TypeScript learning path. TypeScript is a
statically-typed superset of JavaScript that compiles to plain JavaScript. This
folder assumes you're already comfortable with the topics in
[../JavaScript/README.md](../JavaScript/README.md).

## How to use this folder
1. Go through the topics in order — types and interfaces come before generics,
   advanced types, and TypeScript-with-React.
2. Try the examples in the [TypeScript Playground](https://www.typescriptlang.org/play)
   or a local project with `tsc`.
3. Use the **Interview Questions** section at the end of each file for quick revision
   before interviews.
